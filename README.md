## Install

Example: to install för Cline:
```
cd $HOME
mkdir .cline
cd .cline

# If you don't have any SKILLS:
git clone https://github.com/etnt/my-skills.git skills

# If you already got some SKILLs, clone it elsewhere and put a
# link to the skills you want to use. Example:
cd skills
ln -s .../my-skills/flutter-app-development .
```
